Added [solve()][esmporium.requirements.solve], which joins a
[Catalogue][esmporium.requirements.Catalogue] to a
[Requirement][esmporium.requirements.Requirement]: the catalogue describes what
exists, the requirement tree describes what an analysis needs, and the solver
works out whether the one can be filled from the other. A requirement is solved
once per group, where `group_by` says how the available data should be grouped when considering whether a requirement is met or not, and
the groups are discovered from the catalogue rather than listed up front.

[SolveResult][esmporium.requirements.SolveResult] sorts every group into
`resolved` (the datasets to run on, by role), `unsatisfied` (a dataset is
missing) and `ambiguous` (several datasets fit one role and nothing chooses
between them)
