Added [esmporium.db.find_parents][], which walks back up the parent chain of a dataset,
searching for the ancestors we do not already hold and stopping at the experiments it is
told to stop at. [esmporium.db.DatasetVersionParent][] records what one source says a
version branched from, [esmporium.db.DatasetParentLink][] the dataset version that
resolved to. Commits once per hop, so an interrupted walk keeps what it learned.

- A version carries one row per source, and sources can disagree;
  [esmporium.db.preferred_parent_info][] picks the one to believe, in
  [esmporium.db.SOURCE_PRECEDENCE][] order.
- Only CMIP7 publishes parent facts in the search index, so for any other project
  `find_parents` needs a `facts_provider` and raises
  [esmporium.db.NoParentFactsProviderError][] without one.
- Which *version* of a parent to use is a choice rather than something published.
  [esmporium.db.ParentVersionChoice][] says how it was made, and a walk that had to
  make one warns ([esmporium.db.ParentVersionDecidedWarning][]).
