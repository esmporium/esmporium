A single host answering a search (or a facet values request) with something we cannot read is now recorded as that host's failure ([CouldNotUseSearchResultsError][esmporium.search.search.CouldNotUseSearchResultsError] or [CouldNotUseAllowedValuesError][esmporium.search.check_query_values.CouldNotUseAllowedValuesError]), rather than aborting the whole multi-host search.
