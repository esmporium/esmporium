[esmporium.headers][] reads variable attributes and the first and last time values of
a file, as well as its global attributes.

- [read_file_header][esmporium.headers.read_file_header] returns the global
  attributes, every variable's attributes and, with `time_bounds=True`, the first and
  last time values and bounds, as
  [FirstAndLastTimeBounds][esmporium.headers.FirstAndLastTimeBounds].
  [read_header][esmporium.headers.read_header] takes the same `time_bounds`.
- Added [read_variable_attributes][esmporium.headers.read_variable_attributes] and
  [read_first_and_last_time_bounds][esmporium.headers.read_first_and_last_time_bounds].
  A missing variable or attribute raises
  [NoSuchVariableError][esmporium.headers.NoSuchVariableError] or
  [MissingVariableAttributesError][esmporium.headers.MissingVariableAttributesError],
  listing what the file has.
- Every reader takes a [ByteSource][esmporium.headers.ByteSource]:
  [RangeSource][esmporium.headers.RangeSource] for a data node,
  [LocalFileSource][esmporium.headers.LocalFileSource] for a file on disk, or
  [HeldBytesSource][esmporium.headers.HeldBytesSource] for bytes in memory. A source
  fetches only the bytes a reader asks for, at least `block_bytes` at a time, and
  raises [TruncatedHeaderError][esmporium.headers.TruncatedHeaderError] past
  `max_bytes` or `max_requests`.
- A data node which does not serve byte ranges is recorded as `RANGES_NOT_HONOURED`
  and not retried.
