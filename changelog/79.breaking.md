A catalogue entry is one dataset version.

- [CatalogueEntry][esmporium.requirements.CatalogueEntry]'s `id` is the
  `DatasetVersion` id, and it requires `version`, `is_latest` and `retracted`. Every id
  a solve reports is a version id.
- `find` returns the newest version of each dataset that passes the `VersionFilter`,
  and the entry's facets come from that version's documents only. A dataset with no
  versions is never found.
- `parent_of` returns the parent version the link records, and the `VersionFilter`
  only checks it.
- `parent_of_dataset` is renamed [parent_of_version][esmporium.db.parent_of_version].
  `describing_version` and `version_filter` were removed.
- `EnrichmentInput.dataset_id` is renamed `dataset_version_id`.
- [plan_downloads][esmporium.db.plan_downloads] and `download` plan exactly the
  entries' versions, and lost `latest_version_only`.
