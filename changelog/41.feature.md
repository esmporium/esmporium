Renamed the original `search` function to `search_single_project`, and added a new `search` function which accepts multiple search queries with one or more projects. For a search with multiple queries, we added the option to parallelise - to process multiple queries at once - with a pre-built processor for processing results into the database in a parallel-safe way ([build_result_processor_factory][esmporium.db.build_result_processor_factory]). Multi-project search and parallelisation has been added to [check_query_values][esmporium.search.check_query_values] to mirror the search step.
