[solve][esmporium.requirements.solve] now tells the catalogue which facets it will read, so a requirement naming only facets Dataset has columns for no longer opens any stored search document. It also asks each distinct question once rather than once per leaf per group (82 lookups down to 2, for two leaves and forty models), so a solve reads the database once per leaf and sees one state of it throughout. [facets_read][esmporium.requirements.facets_read] works out the facets; [needs_facets][esmporium.requirements.Catalogue.find] is how they reach a catalogue.
