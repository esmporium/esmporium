Added [esmporium.requirements][], the home for expressing the data an analysis needs and working out whether we have it. Here, the data required for an anlysis (in comparison to a simple search query) requires more complicated logic between datasets, hence is it's own package. The [CatalogueEntry][esmporium.requirements.CatalogueEntry] is a stored dataset as the solver sees it, [Catalogue][esmporium.requirements.Catalogue] is the protocol for searching and accessing entries, and [matches][esmporium.requirements.matches] decides whether an entry satisfies a query written in any query style.
