Added [esmporium.requirements][], the home for expressing the data an analysis needs and working out whether we have it. Here, the data required for an anlysis (in comparison to a simple search query) requires more complicated logic between datasets, hence is it's own package. The [DatasetRecord][esmporium.requirements.DatasetRecord] is a stored dataset as the solver sees it, [Catalogue][esmporium.requirements.Catalogue] is the protocol for searching and accessing records, and [matches][esmporium.requirements.matches] decides whether a record satisfies a query written in any query style.
