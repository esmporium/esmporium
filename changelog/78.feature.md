[Covers][esmporium.requirements.Covers] maps a child onto its parent's axis through
where it branched on each.

- A point in the child's data lands on the parent's axis the same distance after the
  branch as it is on the child's. Parent and child may count from different dates,
  and have to share a step and a calendar.
- Where `branch_time_in_child` is not published, the child's project decides, through
  [branch_time_in_child_convention][esmporium.datasets.branch_time_in_child_convention].
  A CMIP5 child is assumed to start at its first time bound, and every answer built
  on that says so, a pass included. A fix which states `in_child` replaces it.
- Every join along a chain is checked: a child has to hold data where it branched,
  and a parent has to run up to it.
- Added `Position`, a number together with the axis it
  is read off, and `TimeRange.holds` and `TimeRange.runs_up_to`.
- A pass which rests on an assumption is kept as a note on the solution.
- When the covered run is too short for the overlap wanted, the message says so.
