- Removed `stac_east_n_matches` and `stac_west_n_matches` in favour of
  [stac_n_matches][esmporium.search.search_api_facade.result_parsers.known_result_parsers.stac_n_matches].

  hence nothing is left for a reader per deployment to disagree about.
  West's older spellings are still read, so a node which has not caught up still works.

  The index ignored the names it did not know, so these searches quietly matched
  nothing rather than failing. Any CMIP6 results from this host were empty.
- Corrected what
  [SearchAPICallRecord.attempt_number][esmporium.db.schema.SearchAPICallRecord.attempt_number]
  is documented to mean: one row is recorded per request, hence paging leaves a row per
  page and the count restarts at 1 for each.
