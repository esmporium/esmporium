Added the `reads_file_headers` marker and `make test-headers` for the tests which
really read headers from the live ESGF data nodes, opt-in behind
`--run-reads-file-headers` like our other live-API markers. These fetch about 64 KiB
per file and write nothing to disk, so they are much cheaper than `make
test-downloads` -- but they do depend on a data node answering, and 3 of 47 timed out
when sampled.
