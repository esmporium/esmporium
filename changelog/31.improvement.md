- Merged `ESGFNGCMIP6ResultParser` and `ESGFNGCMIP7ResultParser` into a single [ESGFNGResultParser][esmporium.search.search_api_facade.result_parsers.known_result_parsers.ESGFNGResultParser].
  Both ESGF-NG deployments write the project in the STAC `collection` field for every project, so there was nothing left for the two parsers to disagree about.
- Gave the places where we read a value out of a search API's response a real error instead of a bare `KeyError`.
  [UnreadableResponseError][esmporium.search.apis.protocol.UnreadableResponseError]
  (and [read_response_path][esmporium.search.apis.protocol.read_response_path], which raises it) says what we wanted,
  where we looked, which keys the response did carry, which API answered and where to report it.
  [NoSearchResultNumberOfMatchesReturnedError][esmporium.search.apis.protocol.NoSearchResultNumberOfMatchesReturnedError],
  [NoSearchResultDocumentsError][esmporium.search.apis.protocol.NoSearchResultDocumentsError],
  and [NoFacetValuesReturnedError][esmporium.search.apis.protocol.NoFacetValuesReturnedError]
  are now subclasses of it, so `except UnreadableResponseError` catches the whole family.
