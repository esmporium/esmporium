- ESGF-NG searches no longer lose a mirror's description of a dataset. Both
  `search.east.esgf.io` and `search.west.esgf.io` index the same datasets but do not
  record the same facets, and because a STAC document's id carries no host, both
  mirrors issue the same id for one dataset version. Only the first was stored, so a
  facet recorded by just one mirror was lost and re-searching could not recover it.
- Solr is unaffected: its ids already carry the data node, so the number of stored
  documents is unchanged.
