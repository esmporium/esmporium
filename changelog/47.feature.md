 Added [esmporium.requirements.Requirement][], which allows users to specify their analysis' requirements. This is handled as a tree. A [Leaf][esmporium.requirements.Leaf] is the end of a branch in the requirements tree. It is identified by a query, which may be written in any query style and is stored as [QueryCanonical][esmporium.query.QueryCanonical]. Nothing is searched or solved here.

 Use [leaf()][esmporium.requirements.leaf], [all_of()][esmporium.requirements.all_of] and [requirement()][esmporium.requirements.requirement] to write a requirement. The models [Leaf][esmporium.requirements.Leaf], [AllOf][esmporium.requirements.AllOf] and [Requirement][esmporium.requirements.Requirement] remain what a stored requirement loads back into.
