Added [Ancestors][esmporium.requirements.Ancestors], so a requirement can ask for the
control a run branched from: it follows the parent links a
[find_parents][esmporium.db.find_parents] walk recorded, back to the experiment it is
told to stop at. Set it with
[Leaf.with_lineage][esmporium.requirements.Leaf.with_lineage], on a leaf or on a node
above it, and each dataset it reaches fills a role of its own -- `control.tas` where it
stopped, `chain.0.tas` for a parent in between.

- [Catalogue.parent_of][esmporium.requirements.Catalogue.parent_of] answers with a
  reason rather than a parent or nothing
  ([ParentStatus][esmporium.requirements.ParentStatus]): a dataset nobody has read a
  parent for yet is work waiting to be done, not a dataset without a parent.
  [parent_of_dataset][esmporium.db.parent_of_dataset] is the same lookup for a caller
  who wants one session across a whole solve.
- A lineage walks back from its dataset and never to it, so a leaf which can only
  select datasets matching `until` is refused
  ([LineageStartsAtTargetError][esmporium.requirements.LineageStartsAtTargetError]):
  `find_parents` stops at such a dataset and records no parent for it.
- [SearchPlan.ancestry_until][esmporium.search.SearchPlan.ancestry_until] carries where
  each lineage stops, which is what `find_parents` has to be told. A search still does
  not follow parent links; that stays an explicit call.
