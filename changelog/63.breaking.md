- Renamed `DEFAULT_SELECTOR` to
  [DEFAULT_SEARCH_API_SELECTOR][esmporium.search.DEFAULT_SEARCH_API_SELECTOR], now
  that there is a data node selector to tell it apart from
  ([DEFAULT_DATA_NODE_SELECTOR][esmporium.downloads.DEFAULT_DATA_NODE_SELECTOR]).
- Moved `curl_equivalent` and `log_request_as_url_and_curl` out of
  [esmporium.search][] into [esmporium.http][], because rendering a request so a
  human can reproduce it is not specific to searching.
  [log_request_as_url_and_curl][esmporium.http.log_request_as_url_and_curl] now takes
  the caller's logger, host and `host_field`, so a log record is attributed to the
  code that made the request rather than to the helper, and a log aggregator does not
  have to guess whether a `host` field means an index node or a data node.
