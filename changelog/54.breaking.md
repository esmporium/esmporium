- [ParsedDocument][esmporium.search.ParsedDocument] now requires a `search_host`, the
  host we asked. If you supply your own result parser (see
  [ResultParserProtocol][esmporium.search.ResultParserProtocol]), set it from your
  API's host. It is not the data node: that is a fact about the dataset and is read
  out of the document, while this is which endpoint answered.
- [DatasetRawDoc][esmporium.db.schema.DatasetRawDoc] gained
  [search_host][esmporium.db.schema.DatasetRawDoc.search_host] and is now unique on
  `(esgf_doc_id, search_host)` rather than `esgf_doc_id` alone. A migration is
  included; rows written by an earlier version get an empty `search_host`.
