- Anchored `downloads/` to the repository root in `.gitignore`. Unanchored, it matched
  any directory of that name at any depth, so `src/esmporium/downloads/` and both of
  its test directories existed on disk, passed every check, and were simply absent
  from the repository.
- Added the `downloads_data` marker and `make test-downloads` for the tests which
  really download files from the live ESGF data nodes, opt-in behind
  `--run-downloads-data` like our other live-API markers. The files are CMIP7
  `areacella` (~51 KB), so the live run takes about 7 seconds.
