[Covers][esmporium.requirements.Covers] with `align="branch"` now judges a covering
dataset any number of branches above its target: the target and every parent up to it
are judged as one series, mapped onto the covering dataset's axis a branch at a time.
The span needed starts where the run directly below the covering dataset branched off
it, so a control has to cover the run asked for and every parent back up to itself. A
gap in any of them, or a run which branched where its parent holds no data, is a
failure.

- `mode="overlap"` measures `min_overlap` from that same point, and the data it
  overlaps with is the whole series, so a target shorter than `min_overlap` can still
  meet it.
- [SolveResult.enrichment_inputs][esmporium.requirements.SolveResult] can name a
  parent in between, not only the two datasets the check names.
