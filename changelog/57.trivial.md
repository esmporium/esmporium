Added live integration tests for CORDEX-CMIP6 and CMIP6Plus, two projects which have neither a search API facade nor a query class, pinning what a caller has to inject to search a project esmporium does not know about. The CORDEX tests cover both ways to reach a facet no query class of ours names -- the `other_terms` escape hatch, and a query class of your own -- and pin that the two build the same search request. The CMIP6Plus tests cover the cheap case, where CMIP6's own query style, facade parameters and facade are all reusable unchanged, over both the ESGF1 Solr and the ESGF-NG STAC APIs.
