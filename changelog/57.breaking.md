Removed `CMIP6Plus` from
[PROJECT_QUERY_MAP_DEFAULT][esmporium.query.PROJECT_QUERY_MAP_DEFAULT].
A `CMIP6Plus` query used to translate with nothing injected and then had nowhere to be
searched, because [DEFAULT_SELECTOR][esmporium.search.DEFAULT_SELECTOR] has no
`CMIP6Plus` facade, which made a project we cannot search look like one we can.
The default mapping is now the same projects the default selector knows.
To search `CMIP6Plus`, pass `project_query_map={"CMIP6Plus": QueryCMIP6}` and a
selector built over a facade of your own;
`tests/integration/requirements/test_cmip6plus_registration.py` is a worked example,
and CMIP6's own query style and facade parameters can be reused unchanged for both
the Solr and the ESGF-NG APIs.
