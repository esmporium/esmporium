Added [esmporium.db.File][] and [esmporium.db.DataAccess][], which record what a dataset version is made of and every way of getting it: one row per file, one row per route per node. A route's `file_id` is `NULL` when it serves the whole version, which is how a kerchunk aggregation, a Globus directory link or a future zarr store is recorded. [esmporium.datasets.AccessService][] and [esmporium.datasets.ContainerFormat][] say how the bytes move and what the bytes are, which vary independently.

- ESGF-NG carries its files in the search response, so they are recorded by [ingest_parsed_documents][esmporium.db.ingest_parsed_documents]. Solr publishes none on a dataset document, so [esmporium.db.record_solr_file_access][] fetches them in a second `type=File` request.
- [decode_multihash_checksum][esmporium.search.decode_multihash_checksum] turns STAC's multihash into a digest and an algorithm name, so a checksum from either API means the same thing and the two can be compared.
